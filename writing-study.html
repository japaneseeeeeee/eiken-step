6 MINI LESSONS

5分でわかる基礎講座

01

採点基準

4つの観点を知る

英検2級では、内容・構成・語彙・文法を各4点、合計16点で評価します。

内容意見と理由2つがある
構成流れとつなぎ言葉が明確
語彙適切な単語を使えている
文法正しい文を幅広く使う

合格のコツ：難しい表現より、質問に正しく答えて80〜100語にまとめることを優先しましょう。

02

基本の型

4段落で組み立てる

最初に型を決めると、途中で何を書くか迷いません。

1

意見
I think that ...

2

理由1＋説明
First, ... because ...

3

理由2＋説明
Second, ... For example, ...

4

まとめ
For these reasons, I believe ...

語数の目安：意見15語＋理由1を25語＋理由2を25語＋まとめ15語で約80語です。

03

意見

最初の1文で立場を示す

賛成か反対かを曖昧にせず、TOPICの言葉を使って答えます。

GOOD

I think that students should use tablets at school.

AVOID

Tablets are used by many people.

質問が Do you think ...? なら I think that ...、Should ...? なら I think ... should ... が使えます。

04

理由

「理由＋説明」で広げる

理由だけで終わらず、because、具体例、結果のどれかを足すと内容点が上がります。

理由Tablets are convenient.

なぜ？Students can carry many books in one device.

結果Therefore, their school bags will be lighter.

自分への質問：「なぜ？」「例えば？」「その結果は？」のどれかに答えて1文を足しましょう。

05

構成と語彙

つなぎ言葉を使い分ける

順番First, / Second,
理由because / since
追加Also, / In addition,
具体例For example, / For instance,
対比However, / Although ...
結果Therefore, / As a result,

同じ表現を何度も使わず、役割に合わせて3〜5個入れるのが目安です。

06

見直し

最後の3分で4点を守る

  • □ 80〜100語になっている
  • □ 意見と異なる理由が2つある
  • □ 文頭は大文字、文末にはピリオドがある
  • □ 三人称単数の動詞、単数・複数を確認した
  • □ 同じ単語を繰り返しすぎていない

おすすめ：答案を小さな声で読むと、抜けた単語や不自然な文を見つけやすくなります。

PHRASE BANK

そのまま使える表現集

丸暗記ではなく、自分の意見に単語を入れ替えて使いましょう。

意見を述べる

I think that ...

In my opinion, ...

I agree that ...

I do not think that ...

理由を説明する

One reason is that ...

This is because ...

For example, ...

This will help people ...

利点を伝える

It is useful for people to ...

People can save time by ...

This is good for the environment.

It gives people a chance to ...

まとめる

For these reasons, I believe ...

Therefore, I think ...

In conclusion, ...

Overall, this will benefit ...

WRITE IT YOURSELF

実際に書いて練習

短い1文から始めて、最後に80〜100語の答案を組み立てます。入力途中はこの端末に自動保存されます。

STEP 1

意見を1文で書く

TOPIC：Should students use tablets at school?

ヒント

I think that + 主語 + should ...

STEP 2

理由と説明を書く

POINT：Convenience

ヒント

First, 理由 because 説明.

STEP 3

具体例を加える

IDEA：One tablet can contain many books.

ヒント

For example, students can carry many books in one device.

STEP 4

意見をまとめる

GOAL：最初の意見をもう一度伝える

ヒント

For these reasons, I believe students should use tablets at school.
